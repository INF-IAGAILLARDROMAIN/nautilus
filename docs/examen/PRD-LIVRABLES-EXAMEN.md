# PARTIE A — Dossier Professionnel (DP)

## A.1 Définition & objectif

Le DP est un **document officiel du Ministère du Travail** (version 1er juin 2016), obligatoire pour la validation du Titre Professionnel. Il présente au jury **des exemples concrets de la pratique professionnelle** du candidat, issus :
- de la formation en centre, et/ou
- de périodes en entreprise.

**Le jury lit le DP AVANT l'oral** pour préparer ses questions. Il n'est pas noté en lui-même mais sert de base à l'entretien final.

## A.2 Format & règles formelles

| Règle | Spécification |
|---|---|
| Modèle obligatoire | Modèle officiel Ministère (.docx fourni par Studi) — **ne pas en modifier la structure** |
| Format de fichier accepté Studi | `.doc`, `.docx`, `.pdf` uniquement (tout autre format est rejeté) |
| Volume cible | ≤ 30 pages (au-delà, risque de non-lecture par le jury) |
| Style | "Je", présent, vocabulaire professionnel / jargon métier |
| Numérotation | Toutes les pages numérotées |
| Reliure | Agrafé ou relié quand complet |
| Exemplaires papier le jour J | **2 exemplaires signés et reliés** |
| Mention "Modalité d'accès" | Cocher **"Parcours de formation"** |

## A.3 Structure obligatoire du DP (8 sections)

1. **Page de garde** : nom de naissance, nom d'usage, prénom, adresse, titre visé en toutes lettres, modalité d'accès cochée
2. **Sommaire** (à rédiger en dernier, avec numéros de pages)
3. **Activité-type 1 — Front-end** : 1 à 3 exemples maximum
4. **Activité-type 2 — Back-end** : 1 à 3 exemples maximum
5. **Titres, diplômes, CQP, attestations de formation** (facultatif)
6. **Déclaration sur l'honneur** : nom, prénom, lieu, date, **signature**
7. **Documents illustrant la pratique professionnelle** (facultatif, max 2 par activité-type)
8. **Annexes** (uniquement si le Référentiel de Certification le prévoit)

## A.4 Contenu détaillé d'un exemple

Chaque exemple = **3 pages maximum**, en suivant strictement cette trame :

### A.4.1 En-tête
- **Intitulé de l'activité-type** (en haut, tel qu'il figure dans le REAC)
- **Intitulé de l'exemple** (court, clair, descriptif)

### A.4.2 Les 5 rubriques

| # | Rubrique | Contenu attendu |
|---|---|---|
| 1 | **Décrivez les tâches ou opérations effectuées + conditions** | Comment tu procèdes pas à pas : étapes, ordre, règles de sécurité/hygiène |
| 2 | **Précisez les moyens utilisés** | Outils, langages, frameworks, IDE, logiciels, documents techniques, machines |
| 3 | **Avec qui avez-vous travaillé ?** | Collègues, formateurs, clients, hiérarchie + **rôle précis de chacun** |
| 4 | **Contexte** | Nom de l'entreprise/centre + période (du JJ/MM/AAAA au JJ/MM/AAAA) |
| 5 | **Informations complémentaires** (facultatif) | ≤ 10 lignes : conditions, contraintes, raison du choix |

## A.5 Règles de contenu

### À FAIRE
- Choisir des exemples **réellement réalisés** par toi (pas observés)
- Choisir des exemples **différents** entre eux
- Couvrir **les 2 activités-types** (front et back)
- Utiliser **le jargon métier** (le jury est composé de pros)
- Faire relire la version finale par le formateur

### À NE PAS FAIRE
- Joindre un CV
- Joindre un rapport de stage
- Joindre une appréciation de tuteur
- Joindre un document de présentation de l'entreprise
- Modifier la structure du modèle officiel
- Dépasser 30 pages

# PARTIE B — Dossier Projet

## B.1 Définition & objectif

Le Dossier Projet est le **document écrit qui rend compte du projet de fin de formation**. C'est lui qui sert de support à la **soutenance orale** devant le jury.

Il démontre, projet à l'appui, la couverture des compétences des 2 activités-types (BC01 + BC02).

## B.2 Format & règles formelles

| Règle | Spécification |
|---|---|
| Format de fichier accepté | `.pdf`, `.doc`, `.docx`, `.xls`, `.xlsx`, `.odt`, `.rtf`, `.txt`, `.html`, `.zip` (20 Mo max) |
| Volume corps | Entre **30 et 50 pages** (hors page de garde, sommaire, annexes), schémas et illustrations compris |
| Volume annexes | **30 pages maximum** |
| Compatibilité | Doit être compatible avec le contrôle anti-plagiat |
| Présentation orale | Support de présentation obligatoire (diaporama) |

## B.3 Choix du plan : projet "en entreprise" vs "en formation"

Le candidat doit choisir entre deux plans selon le contexte de son projet :

### Plan A — Projet réalisé en entreprise (RECOMMANDÉ — plan riche)

Section obligatoire :
1. **La liste des compétences du référentiel couvertes par le projet**
2. **Le contexte du projet** :
   - Présentation de l'entreprise et du service
   - Cahier des charges / expression des besoins
   - Contraintes du projet, livrables attendus
   - Environnement humain et technique, objectifs de qualité
3. **Réalisations front-end** (éléments les plus significatifs + arguments des choix, y compris sécurité) :
   - Maquettes web ET web mobile
   - Schéma d'enchaînement des maquettes
   - Captures d'écran des interfaces web ET web mobile
   - Extraits de code d'interfaces utilisateur **statiques**
   - Extraits de code de la partie **dynamique** d'interfaces utilisateur
4. **Réalisations back-end** (éléments les plus significatifs + arguments des choix, y compris sécurité) :
   - **Présentation de la BDD** :
     - Schéma conceptuel (MCD) avec données et relations
     - Schéma physique (MPD)
     - Script de création ou de modification
   - Extraits de code de **composants métier**
   - Extraits de code de **composants d'accès aux données**
5. **Présentation d'éléments de sécurité de l'application**
6. **Jeu d'essai** sur la fonctionnalité la plus représentative :
   - Données en entrée
   - Données attendues
   - Données obtenues
   - Analyse des écarts éventuels
7. **Veille sur les vulnérabilités de sécurité** :
   - Description de la veille effectuée durant le projet
   - Vulnérabilités éventuellement trouvées
   - Failles potentiellement corrigées

### Plan B — Projet réalisé pendant la formation (plan court)

1. La liste des compétences mises en œuvre dans le cadre du projet
2. L'expression des besoins du projet (objectifs et limites)
3. L'environnement technique
4. Les réalisations permettant la mise en œuvre des compétences

### Recommandation

**Choisir le Plan A** : il offre une démonstration plus complète et donne plus de matière pour la soutenance orale. Il permet aussi de structurer le projet autour d'un vrai contexte (entreprise, utilisateurs, contraintes), ce qui rend la défense plus solide.

## B.4 Annexes (30 pages max)

Pour un projet **en entreprise** (Plan A), les annexes comportent les éléments de la **fonctionnalité la plus représentative** :
- Maquettes des interfaces utilisateur
- Captures d'écran des interfaces + code correspondant
- Code des composants métier les plus significatifs
- Code des composants d'accès aux données les plus significatifs

## B.6 Procédure officielle de dépôt (à chaque dépôt sur la plateforme)

1. Aller dans l'évaluation concernée → repérer la zone **"Fichier(s) à rendre"**
2. Cliquer **"Déposer mon fichier"** → sélectionner le fichier sur l'ordinateur
3. Attendre la fin du chargement (le bouton "Ajouter" se dégrise)
4. **CONTRÔLER** :
   - Bon fichier (cliquer dessus pour le re-télécharger et vérifier)
   - Bonne version
   - Bon format
5. 🔴 **Cliquer "Soumettre mon évaluation"** — étape critique sans laquelle le dépôt n'est pas finalisé
6. Confirmer en cliquant **"Valider"** dans la fenêtre de validation
7. Vérifier le statut **"Transmis pour correction"** en haut à droite (bandeau violet)

> ⚠️ Une fois soumis, le fichier ne peut plus être modifié.
> 💡 Si plusieurs fichiers et un seul espace de dépôt → **fusionner en un seul PDF**.
> 💡 Toujours **garder une copie locale** dans un dossier "Évaluations".

# 5. Distinction DP vs Dossier Projet

| Critère | Dossier Professionnel (DP) | Dossier Projet |
|---|---|---|
| Objet | Présenter ta pratique professionnelle | Présenter un projet de fin de formation |
| Forme | 1 à 3 exemples par activité-type | Un projet unique avec contexte/réalisations |
| Volume | ≤ 30 pages | 30-50 pages + 30 d'annexes |
| Style | Récit subjectif au "je", présent | Document technique structuré |
| Modèle | Modèle Word officiel **obligatoire** (Ministère) | Plan libre (A ou B) |
| Noté ? | Non (support entretien final) | Non (support soutenance orale notée) |
| Lecture jury | Avant l'oral, pour préparer questions | Pendant la soutenance et Q/R |
| Annexes | Facultatives (max 2 docs par activité-type) | Obligatoires si Plan A (max 30 pages) |
| Sources possibles | Toutes expériences pro réelles | Projet unique de formation |
| Exemplaires papier | **2** | **1** |
