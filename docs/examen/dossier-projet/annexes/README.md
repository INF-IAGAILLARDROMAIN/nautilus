1. **Maquettes** des interfaces utilisateur — versions web ET web mobile
2. **Captures d'écran** des interfaces utilisateur (réelles, en production) + le **code correspondant**
3. **Code des composants métier** les plus significatifs (extraits commentés)
4. **Code des composants d'accès aux données** les plus significatifs (extraits SQL + NoSQL)

À placer dans ce dossier au fur et à mesure :
